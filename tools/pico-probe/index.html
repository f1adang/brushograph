Repeatability

Touches the bed where the probe stands, the way a scan does, and says how far apart the readings came out. Start with the pin a few mm above the paper.

Scan

How it touches

The coarse pass jogs down until the pin is touched. The fine pass starts Margin above where that stopped and steps down Fine step at a time, the machine standing still between steps, so the WiFi's delay never reaches the reading. Readings are accurate to one fine step.

Start with the probe a few mm above the first point (X from, Y from). The grid starts at the calibration dot, where the map is read as nought.

Scans

Load a file with Probe map in the Brushograph's Bed levelling group. Continue carries on a scan that ended early, in the same file; a file kept elsewhere is loaded onto the Pico first.
